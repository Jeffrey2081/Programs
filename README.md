# ☕ Java Computer Science & Algorithms Archive (Classes IX – XII)

A comprehensive academic archive of computer science projects, object-oriented implementations, data structures, and mathematical algorithms written in Java (BlueJ environment) throughout high school (ICSE / ISC curriculum).

---

## 📚 Curriculum Breakdown

### 📘 Class IX (Foundational Programming)
Introduction to conditional statements, nested loops, and number theory:
- **`Duck.java`**: Duck number verification (number containing zero not at the beginning).
- **`Dudeney.java`**: Dudeney number validation (cube root equals the sum of digits).
- **`GCD.java`**: Greatest Common Divisor calculation using Euclidean algorithm.
- **`SumSeriesEven.java`** / **`SumSeriesOdd.java`**: Mathematical series accumulation algorithms.

### 📗 Class X (Object-Oriented Basics & Arrays)
Core OOP principles, searching, sorting, and user-defined classes:
- **`Bank.java`**: Banking transaction account class with balance tracking.
- **`BinarySearch.java`**: $O(\log n)$ search on sorted arrays.
- **`LinearSearch.java`**: Sequential linear scan.
- **`CharBubbleSort.java`**: Alphabetical bubble sort on character arrays.
- **`EvenPal.java`**: Even-length palindrome verification.
- **`courier.java`**: Parcel shipping calculation system.
- **`DigitSum.java`**: Recursive and iterative digit summation.

### 📙 Class XI (Data Structures & Matrix Operations)
Advanced arrays, string manipulation, and custom abstract data types:
- **`CircularQ.java`**: Implementation of a circular queue buffer.
- **`BoundSort.java`**: Boundary matrix sorting and traversal.
- **`Adder.java`**: Multi-dimensional matrix addition and transformations.
- **`Alliquot.java`**: Aliquot sequences and perfect number validation.
- **`Codes.java`**: Caesar and substitution cipher implementations.
- **`Arrange.java`**: In-place array rearrangement.

### 📕 Class XII (Advanced Algorithms & Matrix Theory)
Data structure mastery, matrix logic, and parsing:
- **`MagicMatrix.java`**: Magic square validation and generation (row, column, and diagonal sums equality).
- **`Markov.java`**: Stochastic state transition matrix simulator.
- **`MixArray.java`** / **`Mixer.java`**: Array merge and interleaved interleaving algorithms.
- **`Paragraph.java`**: Text parser analyzing sentences, word frequencies, and character statistics.
- **`OddEven.java`**: Odd-even matrix segmentation.

## 🚀 How to Compile & Run

### Using BlueJ
Open any folder (`Class IX`, `Class X`, `Class XI`, `Class XII`) directly as a project in [BlueJ](https://bluej.org/).

### Using Command Line (Terminal)
```bash
# Navigate to any folder
cd "Class X"

# Compile any Java file
javac BinarySearch.java

# Run
java BinarySearch
```
